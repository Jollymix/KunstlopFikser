# Kunstløpassistenten

Et program for kunstløpstevner med to deler:

- **Tidsplan**: Hent deltakerlisten fra isonen, eller legg inn utøvere selv for mindre stevner. Sett starttid, lengde på løp, pause mellom løp, oppvarming og antall vanningspauser. Flytt utøvere opp og ned, så oppdateres tidene med en gang. Startlisten lagres som Excel og PDF.
- **Musikk**: Velg musikk-zip fra stevnedatabasen og spill av musikken underveis, i programmet eller i VLC. Kryss av løp som er gjennomført.

Du får en stor klokke øverst. Start med `start_fms.bat`.
